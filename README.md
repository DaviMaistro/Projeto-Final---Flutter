Saborê - Aplicativo de Receitas

Aplicativo feito em Flutter para ver receitas, pesquisar pelo nome, ler os ingredientes e o modo de preparo e favoritar receitas. As receitas vêm da API DummyJSON Recipes (https://dummyjson.com/docs/recipes).

Funcionalidades
Tela inicial com botão de buscar receitas e lista de receitas, carregada assim que o app abre
Lista com nome e imagem de cada receita
Pesquisa por nome na API, sem aceitar campo vazio ou só com espaços, com botão para limpar a pesquisa
Tela de detalhes com ingredientes e modo de preparo
Favoritos: adicionar e remover receitas, sem repetir, e uma aba para ver os favoritos
Indicador de carregamento enquanto busca os dados
Mensagem de erro com botão de tentar novamente
Mensagens diferentes para busca sem resultado e para nenhum favorito
Ao voltar dos detalhes, a lista e a pesquisa continuam como estavam

Dependências
http

SDK usado: 
Flutter 3.47.8
Dart 3.13.7

Como executar
1 - Abrir o Flutter com um emulador Android aberto
2 - Selecionar o emulador na parte superior da tela e clicar no icone de play verde
